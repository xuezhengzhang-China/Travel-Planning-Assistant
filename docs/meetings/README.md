# 会议记录

此目录用于 `meeting-records` 分支维护真实会议纪要、决策和行动项。工程与功能分支同样保留本目录，会议记录通过正常 PR 汇入 `main`，便于全员查阅。

- 新会议复制 [会议记录模板](会议记录模板.md)，命名为 `YYYY-MM-DD-会议主题.md`。
- 记录实际参会人、讨论、决定、受影响模块/分支、责任人、截止日期和完成证据。
- 未决定的事项写“待确认”，未执行的测试写“未执行”，不填造假的通过率。
- 纪要提出的接口/代码变更交对应功能分支实现，纪要中链接相关提交或 PR。

2026-11-21 的分支组织决定见 [分支重建记录](2026-11-21-分支重建记录.md)。该文件记录本次仓库整理的已知事实，不是补写的团队会议纪要。
