乡镇街道名单 streets.json 来自 modood/Administrative-divisions-of-China：
https://github.com/modood/Administrative-divisions-of-China/blob/master/dist/streets.json

省市县目录 pca-code.json 来自同项目：
https://github.com/modood/Administrative-divisions-of-China/blob/master/dist/pca-code.json
用于行程目的地的本地搜索、按省浏览，包含地级地区和县级市、县区。
港澳台常用目的地在 destinations.ts 中补充；手工补充项的目录键不作为行政区划代码使用。

数据版本为 2023 年统计用区划代码（截至 2023-06-30），项目已停止更新。
源项目许可证：WTFPL。名单用于县区下的乡镇、街道选择与独立点亮，
不包含乡镇边界或坐标，不用于绘制虚构的乡镇边界。
行政区划可能调整；名单与 DataV 边界数据存在版本差异时，不补造区划。
