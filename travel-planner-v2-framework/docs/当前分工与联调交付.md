## 可以直接接入的能力

- 北京城市、日期、六类偏好、18个带官方来源的景点、搜索选择与推荐理由。
- 按行政区、节奏、估算交通和容量生成完整日期范围；远郊单独一天，未安排景点明确列出。
- 草稿保存、用户列表、详情、继续编辑、名称/日期/排序/景点调整、重排确认、服务端方案确认与每日安排保存。
- 版本保护删除：列表先显示名称及不可恢复提示，调用DELETE时携带expectedRevision；旧版本409、他人或不存在404、成功204无响应体。
- 身份隔离、输入校验、错误提示、请求互斥、部分失败保留资源ID与版本。
- 前后端共用paceSettings：轻松10–18点/最多2处/休息30分钟；经典9–18点/3处/15分钟；充实8–18点/4处/10分钟。

## A 如何接入

```tsx
import TripWorkspace from './features/trip-create/TripWorkspace';

// 正式第二页；getAccessToken来自现有登录模块，保持函数引用稳定。
<TripWorkspace key={user.id} user={user} getAccessToken={getAccessToken} />;
```

api可选参数支持替换请求客户端，onSignOut可选参数由宿主处理退出；仅接子页面也可继续使用NewTripPage的onBack/onSaveDraft/onGenerateProposal/onComplete接口。App.tsx的注册登录只是可替换联调入口，不要求覆盖团队正式页面。

真实页面先GET /places取得数据库资料，再用同一批资料展示与编辑；前端预算不再单独写另一套。无服务端回调的独立NewTripPage仍可用共享JSON离线预览，不能假报云端保存。

## API 清单

除注册登录和健康检查，其余均需Authorization: Bearer令牌。路径前缀/api。

| 方法与路径                                                | 功能                                                              |
| --------------------------------------------------------- | ----------------------------------------------------------------- |
| POST /auth/register、POST /auth/login、GET /users/me      | 现有身份接口                                                      |
| GET /destinations                                         | level/parentId/keyword/page/pageSize，目的地分页                  |
| GET /places                                               | cityId必填，keyword/category/themes/page/pageSize，过滤排序后分页 |
| GET /places/:id                                           | 景点详情，未知坐标和开放时间返回null                              |
| POST /recommendations/places                              | 兴趣排序与理由                                                    |
| POST /recommendations/itinerary、GET /recommendations/:id | 生成和读取带有效期的方案                                          |
| POST /trips、GET /trips、GET /trips/:id                   | 创建、分页和详情                                                  |
| PATCH /trips/:id、PUT /trips/:id/selections               | 更新条件、名称和选择                                              |
| POST /trips/:id/apply-proposal、PUT /trips/:id/schedule   | 确认可信方案及保存每日编辑                                        |
| DELETE /trips/:id?expectedRevision=N                      | 删除当前用户指定版本的行程                                        |
| POST /routes/preview                                      | from/to为GCJ-02坐标，transportMode为walking/transit/driving       |
| POST /locations/reverse                                   | coordinates为GCJ-02坐标，解析地点并只关联已收录城市               |

具体字段以packages/shared/src/auth.ts、places.ts、trips.ts、recommendations.ts和[接口与数据约定](接口与数据约定.md)为准。不要把页面LocalTrip的placeIds数组直接当成正式ScheduleItem日程提交。
