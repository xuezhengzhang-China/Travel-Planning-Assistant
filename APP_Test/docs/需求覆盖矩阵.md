## 2. 额外系统边界

- 注册邮箱唯一和并发：A02/A11；密码不明文落库：A10；真实令牌到期：A13；账号重启后仍可登录：DB05。
- 完整迁移与旧基础库升级：DB01/DB02；应用重启后的全类型持久化：DB03。
- 第二条日程写入失败回滚：T23；同图并发关联保护：U14；上传文件后元数据失败补偿：U12。
- 未知字段/自报身份/SQL 输入/异常脱敏/CORS：A09、T07、D10、J09、SEC01— SEC08。
- 正文脚本不会执行：J06 + UI13；图片认证与 Blob 展示：U07 + UI14。
- 搜索竞态、保存失败、重复确认、过期：UI04、UI07— UI12。
- 真实模型 prompt、原始回复、结构校验与推荐编排：EX01/EX02；实际三交通方式、逆地理、GPS：EX03— EX05。

## 3. 需另行记录的人工/专项检查

以下不被自动化 222/222 代替，也不填为“已通过”：

1. 使用真实浏览器地图 Key，核对实际城市边界高亮、缩放/拖动、标记点击和手账回看；核对边界资源来源。
2. 设备定位权限同意/拒绝、无定位设备、WGS84 转换接通前入口禁用。
3. 键盘操作、焦点顺序、读屏文案和实际截图的遮挡/文字可读性。
4. 约定数据量与并发量后补充长时间负载、延迟、容量和资源泄漏专项；不编造目前没有约定的性能阈值。
5. D 明确文件清理任务/宽限期后，补删除文件失败的可重试清理与临时媒体过期清理测试。
6. 在正式部署环境验证反向代理、TLS、密钥配置、数据库备份恢复；自动化本地测试不等于已部署验收。

若这些项目纳入课程最终交付，应先补明确验收契约与失败用例、升级清单版本，再推动实现与复测。
